# TINY - Changelog

## [1.0.0] - 2026-07-21

### Added
- Completed **TINY** Baby & Kids clothing storefront system.
- Designed 10 mandatory HTML templates with 6 distinct sections per page.
- Created `assets/css/style.css` baseline styling and layout components.
- Added `assets/css/dark-mode.css` color overrides for dark mode.
- Added `assets/css/rtl.css` for full right-to-left language alignment flow.
- Added `assets/css/responsive.css` managing grid breaks and mobile side-drawers.
- Developed `assets/js/main.js` controlling LTR/RTL switching, dark mode saving, and mobile nav hamburger.
- Developed `assets/js/cart.js` controlling the client-side local storage shopping basket and checkout step navigation.
- Developed `assets/js/animations.js` handling coming-soon counters, scroll-reveal transitions, form validators, and accordions.
- Set up beautiful, unique Unsplash photo templates across all pages.
- Excluded admin, user dashboards, and authentication login/signup pages per user request.
